# Order Tracking Screen

A modern mobile-first order tracking interface for an e-commerce application.

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Lucide React Icons
- Framer Motion


## Features

- Mobile responsive design
- Delivery timeline
- Estimated delivery information
- Product summary
- Customer support actions


## Supported Order States

1. Normal Delivery

2. Delayed Order

3. Delivered but Not Received

4. Tracking Not Available Yet
